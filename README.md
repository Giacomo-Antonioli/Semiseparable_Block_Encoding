# Semiseparable block encoding: Qiskit

Qiskit implementation of the block encoding of rank-1 semiseparable matrices.
This branch holds only the working code. Tests, experiments and the FABLE
comparison live on the full branch (`reorganize`) of the same repository.

```
pip install -r requirements.txt
python semiseparable_qiskit.py
```

Status: `semiseparable_qiskit.py` still contains demo and plotting code and
imports `fable`; it is not yet a clean importable module.
